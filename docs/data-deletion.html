データ削除のご依頼方法

ねこしっぽ堂が Instagram・Threads・TikTok の公式連携機能（API）で取得した、あなたに関する情報（コメント・返信・メッセージの本文、ユーザー名、添付画像など）の削除をご依頼いただけます。

ご依頼の手順

  1. Instagram（@nekoshippo.do）または Threads（@nekoshippo.do）に、メッセージで「データ削除希望」とお送りください。
  2. メッセージを送ったアカウントのユーザー名で、当方が保存している情報を探して削除します。
  3. 削除が済んだら、同じメッセージでお知らせします。

SNS 上のコメントそのものは、ご自身で削除できます。各SNSのアプリ連携も、利用者がいつでも解除できます。

Data Deletion Instructions (English)

  1. Send a message saying "Data deletion request" to @nekoshippo.do on Instagram or Threads.
  2. We will find and delete the data we store about the account that sent the message (comment/reply/message text, username, attached images).
  3. We will notify you by message when the deletion is complete.
