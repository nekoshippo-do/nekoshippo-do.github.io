お支払いの前に

制作について、ご確認ください

  • お写真をもとに、その子らしさを大切にお作りします。ただし、まったく同じ姿の再現は難しく、しっぽの形や長さ、細かな毛柄などが異なる場合があります
  • 似顔絵を動画にするときも、動きによってはしっぽの長さや毛柄が崩れることがあります。目立って崩れた動きは候補から外します
  • 似顔絵の修正は3回まで基本料金に含みます。4回目以降は1回100円で、追加修正料は後払いです。追加の修正に進む前に内容と料金をご案内します
  • 似顔絵をご確認・ご了承いただいてから、動画・動くスタンプの制作に進みます。動きの制作開始後は、似顔絵の変更はお受けできません
  • 動きは候補から24個を選んでいただきます。候補にない動きのリクエストは2個まで料金に含み、3個目から1個1,000円です
  • 候補から24個を選んでいただいてから、10日以内に制作し、LINEへ審査を申請します。その後のLINE審査期間は、この10日には含みません。審査通過後に購入URLをご案内します
  • 完成したスタンプを使う際は、制作費とは別にLINE STOREで1セット250円の購入が必要です。追加セットも、それぞれ別途購入が必要です
  • 基本の制作費はご注文時のお支払いです。お支払い後、写真を受け取って似顔絵の制作を始める前は全額返金します。制作開始後は原則として返金できません。LINEの審査に通らなかった場合は全額返金します

詳しい販売条件は 特定商取引法に基づく表記 をご覧ください。ご不明な点は、お支払いの前に 公式LINE でお知らせください。
